## Third-Party Services, Protocols, and Public Data Sources

This project integrates with public Brazilian electoral data endpoints and open-source components maintained by third parties. Their terms of service and licenses apply independently.

### Tribunal Superior Eleitoral (TSE) — Resultados & Dados Abertos

- **TSE Resultados (EA20 static JSON):** <https://resultados.tse.jus.br/oficial/>
- **Portal de Dados Abertos do TSE (CKAN APIv3):** <https://dadosabertos.tse.jus.br/api/3/action/>
- **CDN de Estatísticas do TSE:** <https://cdn.tse.jus.br/>
- **Usage:** Read-only public electoral catalogs, municipal/zone codes, vote tallies, candidate listings, party/federation aggregations, turnout/abstention statistics, and open-data package metadata.

- **Maintainer:** Anthropic / Model Context Protocol contributors

- **Usage:** Core protocol SDK (`@modelcontextprotocol/sdk`).
